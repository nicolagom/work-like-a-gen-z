# Work Like a Gen Z — Interactive Prototype

A mobile-first, clickable prototype for the **Work Like a Gen Z** concept.

## Run it

Open `index.html` in any modern browser. No build step or internet connection is required.

For the most app-like experience, open it on a mobile device or use your browser's responsive device preview.

## What works

- Mood check-in
- No People Pleasing streak
- Gen Z Champion chat with simulated local responses
- “Should I say yes?” decision helper
- “Rewrite this for me” de-millennialiser
- “Is this actually urgent?” reality check
- Daily boundary challenge and Main Character Energy points
- Challenges screen with completion state
- Streak and Boundary Score tracking
- Local persistence via `localStorage`
- Five-tab mobile navigation

## Production next steps

Replace the simulated Champion logic with an AI service, add authentication and a database, implement real daily streak logic, notifications, analytics, safety boundaries, and an onboarding flow.
